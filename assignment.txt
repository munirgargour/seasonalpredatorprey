1 Overview
This milestone represents your first major code deliverable. By now, you should have transformed
your proposal into working code that demonstrates the core functionality of your simulation. This
is a checkpoint to ensure you’re on track for successful project completion.
Purpose of M2
• Verify that implementation has begun substantively
• Ensure your code matches your proposed design
• Identify any pivots or adjustments needed early
• Demonstrate progress toward your simulation goals
2 Deliverables
2.1 GitHub Repository
Your repository should now contain:
Repository Requirements
• Source Code
– Core simulation logic implemented
– At least 2 of your proposed models/algorithms coded
– Basic entity classes/structures created
– Initial data collection mechanisms
• Project Structure
– Logical organization of files/folders
– Appropriate .gitignore for your language
– Dependencies documented (requirements.txt, package.json, etc.)
– Build/run instructions that work
• Version Control Evidence
– Multiple meaningful commits (not just one large commit)
– Commit messages that explain changes
– Evidence of iterative development
